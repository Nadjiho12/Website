# Nadji — Personal Website

A simple, fast personal site for a cybersecurity student and developer: who I am, what I'm building, and how to reach me.

**Live site:** https://nadjiho12.github.io/Website/

## Features

- **Light and dark themes:** follows the visitor's system setting on first visit, then remembers their choice
- **Responsive:** works on desktop and phone, with a collapsible menu on small screens
- **Project cards:** each opens a detail pop-up (close with the × button, Esc, or a click outside)
- **Subtle motion:** scroll reveals, hover effects and a slow ambient glow, all switched off for visitors who prefer reduced motion
- **One HTML file:** no framework, no build step, no dependencies (fonts load from Google Fonts)

## What's on the site

- **About:** background and focus
- **Work:** NASIS, NADIS, an eJPT book in progress, and lab write-ups
- **Skills:** grouped by offensive, defensive, systems, programming and AI for security
- **Contact:** email, GitHub and LinkedIn

## A note on NASIS

NASIS (N-AI Security Intelligence System) is proprietary and closed source. The site gives only a high-level description. No source code or internal design is included in this repository.

## Run locally

Open `website.html` in any browser. There is nothing to install.

## Deploy with GitHub Pages

1. Make sure `website.html` is in the root of the `main` branch.
2. Go to **Settings → Pages**.
3. Under **Build and deployment**, set **Source** to **Deploy from a branch**, then choose **main** and **/ (root)**, and click **Save**.
4. Wait a minute or two. The live URL appears at the top of the Pages settings.
